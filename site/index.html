06 / GOOD QUESTIONS

Before you
press Play.

Ask on GitHub ↗
Does my code leave my computer?+

SpeakHarness reads local session files without writing to them. Speech synthesis and language detection happen locally. Model installation downloads files from upstream hosts; it does not upload conversations. There is no SpeakHarness account or telemetry service. Your coding agent has its own separate privacy policy.

Do I have to restart my coding agent?+

No, not for transcript following. Open Sessions in SpeakHarness, choose an existing supported conversation, then press Play. The optional OMP extension requires restarting OMP once after installing it.

Can I speak commands back to the agent?+

SpeakHarness is a listening companion, not a dictation app. It reads answers; it does not record your microphone or approve actions for you.

Is the browser required?+

No. The desktop app opens its own window and starts the local service. A browser dashboard and terminal reader are optional alternatives, available from source or the Nix CLI package. The Nix flake does not install the Electron app.

What about other agents and languages?+

Native transcript adapters cover OMP, Pi, Codex and Claude Code. Other CLI tools can be launched through speakh run -- <command> for terminal capture, with less structured reading. Narration supports English and Brazilian Portuguese; the app interface is English.

Is it open source?+

Yes. Original SpeakHarness code is MIT-licensed. The bundled ephone phonemizer is GPL-3.0-or-later, so redistributing the combined package must respect those terms. Voice models have their own licenses. See the third-party notices.
